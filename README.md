# Pocketeez

> **Tiny companions for your desktop — made for ATINY.**  
> 把小小的它们放进电最上面的脑里，在日常使用电脑的时候陪着 ATINY。

**Pocketeez** 是由 **Be.honest.** 制作的长期像素桌宠系列，名字来自 **Pocket + TEEZ**。

Pocketeez 计划制作 8 只对应 ATEEZ 8 位成员的独立桌面宠物。每只角色都会拥有自己的名称、像素形象、动作、互动、台词与版本记录，而不只是更换外观的同一套程序。

## 🗺️ Roadmap

### Phase 1 — Eight Individual Pets

分别完成 8 只可以独立运行、独立更新的 Pocketeez。

### Phase 2 — Character Polish

根据实际使用与反馈，继续改善动画、互动、对话、稳定性、性能和视觉一致性。

### Phase 3 — Unified App

未来考虑建立统一的 Pocketeez App，让用户可以在一个程序中选择、放出和管理不同角色。

### Phase 4 — Multi-Pet System

未来支持同时在桌面放出两只或更多 Pocketeez。

### Phase 5 — Pet × Pet Interaction

探索不同角色之间基于距离、状态和特定组合触发的互动。

## 📦 Repository Structure

Pocketeez 采用“系列入口 + 角色独立仓库”的管理方式：

- 本仓库：Pocketeez 系列介绍、开发进度与角色导航
- 每只角色：独立仓库、独立版本号、独立 Release 与更新记录
- 未来统一 App：建立独立仓库与独立版本体系

这种结构可以让每只角色保持自己的个性和发布节奏，同时为未来共享真正通用的代码保留空间。
